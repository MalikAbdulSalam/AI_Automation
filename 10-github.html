Complete Git & GitHub Tutorial

Windows Beginner Guide

What is Git?

Git is a Version Control System (VCS). It keeps track of changes made in your project files.

  • Stores project history
  • Allows multiple developers to work together
  • Restore previous versions
  • Manage project branches

What is GitHub?

GitHub is a cloud platform where Git repositories are stored online.

  • Store source code
  • Backup projects
  • Collaborate with teams
  • Open-source development
  • Portfolio for developers

Git vs GitHub

Git GitHub

Installed on PC Website
Step 1

Create GitHub Account

  1. Visit https://github.com
  2. Click Sign Up
  3. Create account
  4. Verify email
Step 2

Download Git

Download Git from: 

https://git-scm.com/downloads

Install using default settings.

Step 3

Verify Installation

git --version
Expected output: 
git version 2.x.x.windows
Step 4

Configure Git

git config --global user.name "Your Name"

git config --global user.email "your@email.com"

git config --list
Step 5

Create GitHub Repository

  • Login to GitHub
  • Click + icon
  • New Repository
  • Name: MyProject
  • Public or Private
  • Create Repository
Step 6

Create Local Project

cd Desktop

mkdir MyProject

cd MyProject
Step 7

Initialize Git Repository

git init
Output: 
Initialized empty Git repository
Step 8

Create README File

# My First GitHub Project

Hello GitHub!
Step 9

Check Status

git status
Output: 
Untracked files:
README.md
Step 10

Add Files

git add README.md

OR

git add .
Step 11

Commit Files

git commit -m "First Commit"
Step 12

Connect Local Repository to GitHub

git remote add origin https://github.com/username/MyProject.git

git remote -v
Step 13

Push Code to GitHub

git branch -M main

git push -u origin main
Step 14

Modify Project

git status
Edit your files.
Step 15

Stage Changes

git add .
Step 16

Commit Changes

git commit -m "Updated project"
Step 17

Push Again

git push
Step 18

Clone Repository

git clone https://github.com/username/project.git
Step 19

Pull Latest Changes

git pull
Step 20

View Commit History

git log

git log --oneline

Branch Commands

git branch

git branch feature1

git checkout feature1

git checkout -b feature2

git merge feature1

git branch -d feature1

Undo Commands

git restore filename

git restore .

git reset HEAD filename

git reset --hard HEAD
Warning: git reset --hard permanently removes uncommitted changes.

Common Errors

Error Solution
git not recognized Install Git and restart terminal
Permission denied Login to GitHub again
Repository not found Check repository URL
Nothing to commit No changes detected
Merge conflict Resolve conflict manually
