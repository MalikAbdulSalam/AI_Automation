Email Classifier Node Settings

Complete reference for building an AI-powered email router in n8n using Schedule Trigger
n8n v1.0+ Gmail + Sheets LLM (OpenAI / Ollama) Telegram notifications
1. Schedule Trigger
Node type: Schedule Trigger Trigger: Every 5 minutes
Trigger Times
Every 5 minutes (or custom CRON)
CRON Expression
*/5 * * * * (runs at 0, 5, 10, ... minutes past each hour)
Options
Time zone: UTC (or your local timezone)
Ignore previous executions: true (prevents backfill)
Output
No data output – triggers workflow execution; next node fetches emails
Note: The Schedule Trigger does not pass any email data. The Gmail node (next step) will fetch unread emails each time the workflow runs.
2. Gmail Get Messages
Node type: Gmail Operation: Get Messages
Credential
OAuth2 – Gmail (select your connected account)
Filter / Query
is:unread in:inbox -category:promotions -category:social
Max Results
10 (adjust based on volume)
Mark as read
Enabled (prevents re-processing)
Options
Include attachments: false · Format: Full
Important: This node returns an array of unread messages. The workflow will process each email individually.
3. Code (Clean HTML + Extract Fields)
Node type: Code JavaScript (ES6)
Code
const email = $input.first().json; let body = email.bodyHtml || email.body || ''; body = body.replace(/<[^>]*>/g, ' ').replace(/\s+/g, ' ').trim(); return { id: email.id, from: email.from, subject: email.subject, date: email.date, body: body.slice(0, 15000) };
Mode
Run once for each item (default)
4. LLM Chain (Classifier)
Node: AI Agent (or Basic LLM Chain) Model: gpt-4o-mini / ollama/llama3.2
Credential
OpenAI API (or OpenRouter / Ollama)
System Message
You are an email classifier. Classify into: Applied, Offer, Rejection, or Other. Extract company name, job position, and feedback. Output ONLY valid JSON: { "classification": "Applied", "company": "string", "position": "string", "feedback": "string" }
User Message
Email subject: {{ $json.subject }}
Body: {{ $json.body }}
Options
Temperature: 0.0 (deterministic) · Max tokens: 300
Response Format
JSON (enforce via structured output if available)
5. Switch (Route by Classification)
Node: Switch Mode: Expression
Routing Rules
Rules:
Rule 1: classification == "Applied" -> output 0
Rule 2: classification == "Offer" -> output 1
Rule 3: classification == "Rejection" -> output 2
Rule 4: classification == "Other" -> output 3 (fallback)
Data Property
{{ $json.classification }}
Tip: You can add more categories (e.g., Support, Invoice, Personal) by extending the switch rules.
6. Google Sheets (Append Row)
Node: Google Sheets Operation: Append
Credential
OAuth2 – Google Sheets
Spreadsheet ID
1ABC123... (from the sheet URL)
Sheet Name
e.g., Applied (connect to Switch output 0)
Row Data (Columns)
[ {{ $json.date }}, {{ $json.from }}, {{ $json.subject }}, {{ $json.classification }}, {{ $json.company }}, {{ $json.position }}, {{ $json.feedback }} ]
Options
Value render: Auto · Batch size: 1
Duplicate for Offer, Rejection, Other
7. Gmail Add Label
Node: Gmail Operation: Add Label
Credential
OAuth2 – Gmail
Message ID
{{ $json.id }} (from the cleaned email data)
Label Name
Use expression: {{ $json.classification }} (dynamic label)
Or static: Work / Personal
Options
Create label if not exists: Enabled
8. Telegram Notification
Node: Telegram Operation: Send Message
Credential
Telegram Bot token (from BotFather)
Chat ID
123456789 (your user or group chat ID)
Message Text
New {{ $json.classification }} email From: {{ $json.from }} Subject: {{ $json.subject }} Company: {{ $json.company }} Feedback: {{ $json.feedback }}
Parse Mode
None (or Markdown for formatting)
Optional: Add conditional logic to send notifications only for "Offer" or "Rejection" to avoid alerts for every email.

Complete Workflow Overview

Schedule Trigger Gmail Get Messages Code (clean) LLM Classify Switch Sheets / Label / Telegram

Credentials Required

  • Gmail OAuth2 – for reading emails and adding labels.
  • Google Sheets OAuth2 – for appending rows.
  • LLM API – OpenAI / OpenRouter / Ollama (local) – choose one.
  • Telegram Bot – optional, for notifications.

Troubleshooting

  • No emails processed? Ensure the filter is:unread is correct and there are unread emails in the inbox.
  • LLM returns raw text not JSON? Set temperature=0 and enforce JSON in the system prompt.
  • Google Sheets fails? Verify the sheet name and column count match the row data.
  • Telegram not sending? Verify the Chat ID and bot token; test with a simple node first.
  • Schedule not running? Ensure the workflow is set to "Active" and the timezone is correct.
