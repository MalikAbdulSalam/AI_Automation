n8n Email Automation Workflow

Complete step-by-step guide to create an automated email sending system using n8n

📌 Project Overview:
This workflow reads email addresses from an ODS file and a message body from a text file, then sends automated emails using Gmail. Perfect for mass email campaigns and automated notifications.

Prerequisites

  • ✅ n8n instance installed (local or cloud)
  • ✅ Gmail account with OAuth2 credentials
  • ✅ Basic understanding of n8n interface
  • ✅ Node.js (if running locally)

🔧 Step 1: Set Up n8n Environment

1.1 Install n8n

# Using npm
npm install n8n -g

# Or using Docker
docker run -it --rm \
  --name n8n \
  -p 5678:5678 \
  -v ~/.n8n:/home/node/.n8n \
  n8nio/n8n

1.2 Access n8n

Open your browser and go to: http://localhost:5678

Step 2: Set Up Gmail Credentials

2.1 Create OAuth2 Credentials in Google Cloud

  1. Go to Google Cloud Console
  2. Create a new project or select existing
  3. Enable Gmail API
  4. Create OAuth 2.0 credentials
  5. Set redirect URI: http://localhost:5678/oauth2-credential/callback
  6. Download credentials.json

2.2 Add Credentials in n8n

  1. In n8n, go to Settings → Credentials
  2. Click "+ Create"
  3. Select Gmail OAuth2
  4. Fill in:
    • Client ID
    • Client Secret
  5. Click "Connect my account"
  6. Complete OAuth flow

3.2 Node Configurations

Manual Trigger Node

// No configuration needed
Name: "When clicking 'Execute workflow'"

Read File Nodes

// Read_email (ODS)
File Selector: "/home/node/.n8n-files/data.ods"

// Read_mail_body (TXT)
File Selector: "/home/node/.n8n-files/mail.txt"

Extract Nodes

// Extract_email
Operation: "ODS"

// Extract_mail_body
Operation: "Text"

Merge Node

Mode: "Combine"
Combine By: "Combine All"

Gmail Send Node

Send To: "={{ $json.Email }}"
Subject: "Meeting"
Email Type: "Text"
Message: "={{ $json.data }}"

Step 4: Connect All Nodes

1 Manual Trigger → → Read_email & Read_mail_body
2 Read_email → → Extract_email
3 Read_mail_body → → Extract_mail_body
4 Extract_email → → Merge (Index 0)
5 Extract_mail_body → → Merge (Index 1)
6 Merge → → Send a message

Step 6: Test the Workflow

6.1 Execute Workflow

  1. Click "Execute workflow" button
  2. Watch the execution flow in real-time
  3. Check each node's output for data validation
  4. Verify emails are sent successfully
✅ Success Indicators:
  • All nodes show green checkmarks
  • No error messages in node outputs
  • Emails appear in Gmail sent folder

6.2 Troubleshooting

⚠️ File Not Found
Check file path permissions and ensure files exist.
⚠️ OAuth Error
Reconnect Gmail credentials in n8n settings.
⚠️ No Emails Sent
Verify email format in ODS file.
⚠️ Merge Issues
Check merge settings and node connections.
