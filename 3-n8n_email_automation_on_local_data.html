📘 Automated Email System using n8n + ODS + Gmail

🎯 Objective

In this lecture, we build an automated system using n8n workflow automation platform that:

  • Reads data from ODS spreadsheet
  • Extracts email and user data
  • Reads email message from file
  • Merges data
  • Sends bulk emails using Gmail

🧠 1. Introduction to Workflow Automation

Workflow automation connects tasks so they run automatically without manual effort. Each workflow in n8n consists of:

  • Trigger nodes
  • Processing nodes
  • Action nodes

📂 2. Dataset Structure

ODS File (data.ods)

Name | Company | Email
Malik | Inject | malik@gmail.com
Abdul | AI | abdul@gmail.com

Email Body File (mail.txt)

Hi,

Hope you are doing well.
Meeting is scheduled on 26-06-2026.

Regards
Inject AI Solutions

      ↓

      ↓

      ↓

⚠️ 6. Common Problems

  • Only one email sent → wrong merge mode
  • Undefined error → missing field
  • Duplicate emails → same data in ODS

🔁 7. Execution Model

1 item = 1 email sent
6 items = 6 emails sent
